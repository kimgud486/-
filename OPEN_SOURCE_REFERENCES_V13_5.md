# Open Source References V13.5 (Observability & Live Readiness)

AISTOCK v13.5 builds upon key industry open source paradigms for trading observability, latency tracking, and fail-closed readiness:

1. **OpenTelemetry / Prometheus Metrics Specification**
   - Reference: https://opentelemetry.io/ & https://prometheus.io/
   - Application: Observability metrics calculation (order latency, fill latency, stale feed ratio, broker error rate, slippage bps).

2. **Korea Investment & Securities Open Trading API**
   - Reference: https://github.com/koreainvestment/open-trading-api
   - Application: Real-time WebSocket connection monitoring, fill verification, and error code handling.
