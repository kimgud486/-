- **최근 20회 가중**: 무작위와 통계적으로 구별되지 않음 (예측력 없음)
- **직전회차 전이**: 무작위와 통계적으로 구별되지 않음 (예측력 없음)
- **동반출현 친화도**: 무작위 기대치보다 낮음 — 전략이 고른 번호가 오히려 덜 나왔음. 가정과 반대 방향이며, 여러 전략을 동시에 검정할 때 우연히 나올 수 있는 크기
- **앙상블(빈도+최근+전이+동반)**: 무작위 기대치보다 낮음 — 전략이 고른 번호가 오히려 덜 나왔음. 가정과 반대 방향이며, 여러 전략을 동시에 검정할 때 우연히 나올 수 있는 크기
- **균등 추출+패턴 필터**: 무작위와 통계적으로 구별되지 않음 (예측력 없음)

## 왜 계속 틀리는가 (회차별 진단의 공통 결론)
1. **번호 순위에 정보가 없음**: 실제 당첨번호의 모델 순위 평균이 23위 근처(무정보 기준)로, 어떤 점수도 당첨번호를 위로 올려놓지 못했습니다.
2. **풀 적중률 = 풀 크기/45**: 상위 K개 풀에 실제 번호가 들어오는 비율이 정확히 K/45로, 풀 선정이 무작위와 같습니다.
3. **가정 검증 실패**: 핫넘버는 계속 핫하지 않고, 콜드넘버는 '나올 때'가 따로 없으며, 직전 회차 번호 재출현은 기대 0.8개 그대로이고, 동반출현 쌍은 990개 쌍의 자연스런 극값일 뿐입니다.
4. **필터는 확률을 바꾸지 못함**: 필터는 실제 당첨 조합의 일부를 아예 배제하면서도, 남긴 조합의 당첨 확률을 올리지 않습니다.
5. **그래서 틀린 이유는 계산 실수가 아니라 추첨의 독립성**입니다. 매 회차 8,145,060개 조합이 같은 확률을 가지며, 과거 데이터로 이 확률을 바꿀 수 없습니다.
